原功能时序图已整理为三级 PRD。本文保留旧链接的访问入口；需求、时序图和验收标准以各功能 PRD 为准。

| 层级      | 文档                                                                                                                                                                        | 回答的问题                 | 更新频率 |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | -------- |
| L1 项目级 | [项目总体 PRD](../../prd/project.md)                                                                                                                                        | 为什么做、做什么、什么节奏 | 低       |
| L2 模块级 | [身份与用户](../../prd/modules/identity.md)、[个人插件](../../prd/modules/plugins.md)、[对话](../../prd/modules/conversations.md)、[Agent 运行](../../prd/modules/agent.md) | 模块边界、依赖、状态流转   | 中       |

| 功能             | L3 PRD 与时序图                                          |
| ---------------- | -------------------------------------------------------- |
