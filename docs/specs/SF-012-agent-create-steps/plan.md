## 技术方案与理由

1. 在现有AgentEditor创建状态中加入当前步骤，父级仍只保存一份AgentInput草稿。步骤使用现有Badge与非交互有序列表，标明当前步和总步数；不新增依赖或跳过校验的自由跳转。三组原字段按创建步骤条件挂载，已有Agent内联编辑仍一次展示全部字段。
2. 第1步名称/简介/模型，第2步prompt/工具，第3步开场消息及完整只读配置摘要。上一步只切步骤，下一步过滤共享schema的当前步错误；错误就近展示并聚焦，合法才前进。导航保全部输入、稳定模型ID、工具和开场顺序。末步摘要可查看完整prompt和有序开场，不只显示数量。
3. 前两步form submit只执行当前步校验/导航，绝不创建；输入Enter遵守IME composing/keyCode229，textarea保换行。Next使用type=button，最终确认单独key/DOM且type=submit，防止React复用按钮后click默认行为意外提交。末步只有明确最终确认可POST；任何隐式提交不能越过校验或替代确认。最终全schema复验，跨步首错先切步、再等DOM挂载聚焦真实字段。
4. 当前步焦点统一按字段选择：基本信息名称、行为prompt、末步首个开场或可聚焦标题；Dialog初始焦点、步骤切换、继续填写及同账户故障恢复均使用当前可用目标。保留SF011局部PrivatePortalProvider的物理嵌套与授权边界，401/身份变化仍卸载清理。新建/放弃/成功后的下一次打开重置第1步；返回、继续、503恢复、请求失败保步骤和草稿。
5. 同步savingNow互斥保持，pending禁所有前后导航、字段与关闭路径。失败停末步且可重试；成功才合并真实ID、关闭并选中。既有POST/PUT、保存并聊天与方形Agent卡片保持，无后端或持久幂等迁移，不调用云模型，不将草稿写浏览器持久存储。

## 模块、接口与数据流

- 生产：`apps/web/components/agent-editor.tsx`及`agent-editor.styles.ts`，UI规范`docs/ui-design-spec.md`。共享Dialog/Portal原则上保持，出现证据再定位。
- 接口：原contracts校验与`createAgent`、`updateAgent`，同源POST/PUT不变。Web不引入core/db依赖。
- 数据流：同一内存draft → 当前步校验与切步 → 全量确认摘要/校验 → 原POST → 有效saved.id合并列表；错误在对应步呈现。
- 测试：根适配`account-agent-shadcn.test.tsx`原3项Agent行为；评测代理适配`agent-create-dialog.test.tsx`原6项并按需要新增最多2项高价值分步防御用例。不同文件并行，不在src写测试。

## 数据、兼容与迁移影响

- 持久化数据：无表结构、索引或历史记录迁移；真实验收仅新增明确标识且不含秘密的Agent配置，不执行聊天。
- 兼容性：既有Agent字段默认值/可选性、完整内联编辑、PUT及保存并聊天不变。
- 部署/配置：无新依赖和环境变量。生产构建避免与dev并行写`.next`；仅短暂停止自己启动的主launcher，构建后恢复，保数据库/对象服务。

## 风险与缓解

| 风险                                    | 影响             | 缓解                                                                         |
| --------------------------------------- | ---------------- | ---------------------------------------------------------------------------- |
| Enter/direct submit或Next复用submit按钮 | 前步意外创建     | 提交入口守卫、独立key/type、真实DOM零POST断言、IME及textarea验证             |
| 条件字段卸载后的错误/恢复焦点           | 焦点丢失或落背景 | 字段到步骤映射，切步后调度焦点，当前步可用标题fallback，实际AuthBoundary回归 |
| 返回或恢复重置步骤/顺序                 | 草稿丢失         | 父级单份draft；只有明确新开/放弃/成功重置；5条开场前后导航及503覆盖          |
| 最后校验出现前步错误                    | 错误不可见       | 隔离schema结果故障注入，验证零POST、自动回步及挂载后首错，无生产调试入口     |
| UI测试mock误当持久化                    | 假完成           | 独立DOM证状态，真实浏览器POST/刷新重读证持久保存，零云模型调用               |
