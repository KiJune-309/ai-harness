## 背景与问题

SF-002 与 SF-003 已验收通过，系统可以创建真实个人任务、冻结 Agent 配置、在项目中归组并持续执行，但重复开展调研、周报或上线准备时，用户仍要逐次新建项目和各个任务，反复填写相同目标与助手选择。现有代码没有可保存的任务蓝图及批量实例化入口。

用户本轮明确要求继续对标 Syncless：产品经理寻找缺口并写 Spec，主开发者写 Plan/Tasks、实现，再由评测 agent 检查，不再逐阶段向用户确认。此前的阶段评审委托继续有效；本规格交授权评测代表审查，通过后主开发者即可推进。

本轮交付是**个人重复任务清单模板**这一子集。有序条目不代表前后依赖、自动调度或上下游；模板创建、预览和启动不执行模型。具体编辑、版本、幂等及下述交互是本系统设计选择；Chrome现已只读观察模板入口和一份模板设计页，未发送消息、未主动保存或启动外部项目，未实测协作执行。

## 目标

- 用户能够保存并维护一组常用工作目标及助手选择，在后续工作中重复使用。
- 用户预览模板后一次生成完整的新项目和独立真实任务，避免逐个重复创建。
- 实例任务继续使用 DeepSeek Cordis，保持既有任务上下文、明确开始执行、完成恢复与项目归属语义。
- 启动失败、响应丢失或并发修改不会产生半个项目、重复任务，或回滚已经生成项目的后续工作。

## 范围

### 范围内

- 模板入口、真实列表、按名称/说明搜索、稳定详情/编辑与启动预览。
- 创建与编辑模板名称、说明及1–8个有序任务条目；每项包含名称、目标、当前范围 Agent 或通用助手选择，可添加、移除和调整顺序。
- 启动时填写新项目名称及说明，预览全部任务及助手；一次保存新项目、全部任务及初始归属。
- 模板版本与并发编辑保护、创建/启动动作幂等、失败恢复、用户/工作空间隔离和真实持久化。
- 生成后的项目和任务使用已有入口；任务仍由用户逐个明确开始，不自动传播其他任务或项目说明。

### 范围外

- 多成员负责人、团队权限、上下游边、任务依赖、自动接力、定时运行及一键执行所有任务。
- 模板变量/表达式语言、启动时逐项覆盖目标、模板市场、分享、导入导出、历史版本回滚、删除及归档。
- 从已有项目自动反向提取模板；本轮通过明确的模板编辑器维护蓝图。
- 云环境初始化脚本、Secrets、设备、共享文件、知识库及跨任务上下文合并。

## 用户场景

1. 用户创建“每周产品回顾”模板，配置“整理反馈”“分析优先级”“形成行动建议”三个目标，并分别选择合适 Agent。保存后可再次打开修改条目或顺序。
2. 用户在模板预览中填写“第42周产品回顾”及项目说明，确认后一次得到一个真实项目和三个未开始任务；保存本身不产生模型调用。
3. 用户进入其中一个任务明确开始，再补充信息；其他任务仍保留各自目标及消息。随后移动其中一项任务，旧启动请求重放也不会把它移回原项目。
4. 用户修改模板或原 Agent，再次用新的启动动作生成另一项目；新实例使用新版本及启动时的 Agent，旧实例不受影响。
5. 用户遇到网络或持久化故障时，表单、启动参数与动作标识可重试；不会留下只有部分任务的项目。

## 非功能约束

- 延用现有DeepSeek Cordis执行机制与包依赖方向；模板管理和批量内容创建不引入新执行器或额外外部服务。
- 项目名称/说明是管理内容，不自动注入任务；任务模板目标属于用户工作上下文，不替换Agent system prompt或扩大工具授权。
- 同一动作依据原始规范化参数判断幂等，后续资源编辑不改变该判定；首次创建/启动参数与资源当前状态分离。预览版本和编辑版本须可核验，持久化失败不能留下成功幂等占位。
- 有序条目仅保证蓝图及初始生成展示可追溯，不约束用户开始各任务的顺序；不增加项目完成状态或自动启动链。
- 响应、日志、模板和任务中均不存储/公开模型密钥；维持现有签名cookie个人身份，不宣传已有真实团队协作。
- 使用既有视觉变量和键盘/焦点规则，长目标可换行、任务条目操作有可访问名称，390px下核心表单与预览可操作。
- 测试文件放在各模块与`src`同级的`tests`目录，不在`src`内新增测试；测试发现配置随实际路径保持一致。
- 适用测试、类型检查、构建、lint和格式检查通过；实际PG事务/重启与真实DeepSeek验证不能由mock替代。独立评测仅将有证据的验收标PASS。

## 依赖与假设

- SF-002、SF-003已Accepted，现有个人项目/任务/Agent及持久化用于本轮；本轮回归不改变其既有语义。
- 用户已明确授权本轮直接推进并由产品经理/评测代为阶段评审；无新增用户确认步骤。
- 模板引用助手选择，在首次启动时解析当前配置；同次启动每个不同Agent及通用助手各解析一次，同一引用的条目共用该配置快照，各任务消息标识和历史仍独立。不同Agent分别冻结各自解析值，不承诺跨所有Agent的全局版本快照；模板版本固定任务蓝图，不承诺冻结关联Agent到模板保存时点。
- PostgreSQL是正式主记录，memory是显式开发模式。启动原子性包含模型调用之前的内容生成，不含后续人工开始执行的多个任务。
