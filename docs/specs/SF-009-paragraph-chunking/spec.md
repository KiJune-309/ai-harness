## 背景与问题

用户要求“分片首先先按段落，标点符号来分”。当前资料库按 Unicode 字符固定窗口切分，可能把段落和句子从中间截开；数据库完成校验还要求每个非末片达到固定长度、相邻片恰好重叠配置字符数。只改前端说明或只调整 splitter 不能满足要求，需要将真实分片和落库校验一起改为优先自然边界、长度作为硬上限。

本轮延续已授权的 SDD 协作：产品经理编写 Spec，主开发者写 Plan/Tasks 并实现，独立评测 agent 代理审查和验收，无需再次人工确认。现有真实资料、向量索引和已保存模型保持原记录，不借分片策略调整自动重切或发起付费模型请求。

2026-10-18 独立评测 agent 已依据用户既有阶段代理授权审查并批准本规格。已核对当前固定窗算法、PG 固定片长/重叠校验、隔离 worker 的编译产物入口、上传幂等与向量源摘要，要求同时改变算法和完成校验，并保留旧 ready 数据/向量及零自动模型调用。此批准只允许主开发者编写 Plan/Tasks，不提前表示实现或验收通过。

## 目标

- 新执行的资料分片优先保留段落、句子和标点边界，短段可合并，过长连续内容仍不超过用户配置的字符上限。
- 原正文的字符、空白、换行和标点完整保留，每片仍有精确 Unicode 源位置，可按位置去除重叠后完整重建规范化正文。
- 重叠参数成为上限，优先重复完整尾部段/句等自然单元，不为凑够重叠字符数再次截断完整句子。
- 已发布资料、原片 ID/位置、向量及索引来源摘要不变；新旧片均可按现有界面查看，不增加策略选择器。

## 范围

### 范围内

- 调整 TXT、MD、文本层 PDF、DOCX 共用的 core 分片行为，维持现有真实提取和正文规范化规则。
- 自然边界优先、短段合并、长段继续按标点细分、空白/词间间隔和 Unicode 长度兜底。
- 可变实际重叠、严格前进、完整字符覆盖及真实来源位置的持久化校验。
- 按实际产片数量检查 5000 片上限，保留现有正文/文件/页数/参数上限、隔离 worker 与安全错误。
- 上传和详情的必要文案、相应测试、真实数据库及界面回归、逐 AC 记录。

### 范围外

- 语义模型、LLM/NLP 分句、Markdown AST/代码块/表格专用切分、完整英文缩写语法识别，以及新的可选策略或手工分片编辑。
- 已 ready 资料的自动重切、批量迁移、旧片内容/ID/偏移更新、索引失效或重建、自动调用 embedding/聊天模型及额外费用。
- 上传格式、OCR、检索策略、embedding 连接、向量空间及账户权限机制的扩展。

## 用户场景

1. 用户上传有多段落的资料，若干短段能合在一个片内；到达大小上限前优先在段落结束处切开，段落分隔空白仍可见。
2. 用户上传一个超过上限的长段，系统先找句末，再找其他标点；连续无标点长字符串最终按 Unicode 长度切分，始终不超过上限且不切坏 emoji。
3. 用户设置重叠 200 字符，系统重复可以容纳的完整尾部单元；实际可以是 120、40 或 0，而不是硬截一个句子只为凑够 200。查看源位置能确认真实重叠。
4. 用户打开已有资料和已有云向量来源，原片与召回引用仍完全相同；只有新上传或尚未完成处理的资料实际切分时使用新行为。

## 非功能约束

- core 继续负责真实解析/分片，API/DB 继续拥有授权、持久状态、批次与 CAS；不增加模型或新存储服务，不改变包依赖方向。
- 边界查找须适用于最多200万字符的现有资源预算，不能每产生一个短片就无限重扫全文或依赖高风险回溯；具体实现交给批准后的 Plan。
- 所有位置以现有规范化正文为准。段落标点优先不意味着去空格、替换标点或重组段落；极端空白区也必须覆盖，硬字符上限优先于“完整单元”。
- 新增/修改命名函数遵守多行 JSDoc；只保存实际结果，不以演示片段或伪进度替代。

## 兼容性与既有规格变更

- SF-007 的 `chunkSize`/`overlap` 参数字段、允许范围及默认值保持，现有公开 chunk 结构和 Unicode 坐标语义保持。
- 本 Spec 明确替代 SF-007 实施与历史 AC-004 中“非末片长度固定等于 chunkSize、actualOverlap 恰好为配置值”的固定窗判定：新行为允许实际片长更短、重叠在0与上限之间，验证真实坐标和交集。旧规格/验收证据作为历史保留，不回写成从未采用过固定窗。
- 不为区分新旧记录新增必须填写的策略字段或要求迁移；旧固定窗是新安全不变量允许的合法特例。已 ready 记录的 byte/ID/向量一致性须独立验证。

## 依赖与假设

- SF-007/008 的真实提取、持久资料/分片、只读来源和向量功能已存在；本轮不重新请求用户云密钥或触发云测试。
- 单换行作为自然段落/行界纳入，空白行优先于单换行，适用于普通文本和现有 PDF 提取结果；不承诺恢复原文排版语义或识别全部语言缩写。
- 用户已授权产品经理/评测代理阶段审查；本轮没有需要用户阻断性澄清的配置项。
