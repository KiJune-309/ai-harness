# Agent 运行模块 PRD

层级：L2 模块级。状态：设计草案。所属项目：[AI Agent 平台](../project.md)。详细设计见[Agent Harness 技术设计](../../superpowers/specs/2026-10-01-agent-harness-design.md)。

## 模块目标与边界

让 Agent 在服务器上完成模型请求、工具调用、最终回复和事件持久化。`packages/ai-runtime` 在进程启动时装配 Cordis 服务，提供稳定运行入口；它不依赖 NestJS。`apps/api` 先验证身份与权限，传入可信用户和工作空间上下文。

## 能力与依赖

| 能力     | 行为                                               | 依赖                           |
| -------- | -------------------------------------------------- | ------------------------------ |
| 模型循环 | 组装上下文、流式调用模型、按请求继续下一步。       | 模型适配器、会话事件。         |
| 工具派发 | 校验工具和参数，将调用发往当前用户沙箱。           | 个人插件模块、沙箱桥接。       |
| 事件记录 | 保存用户消息、模型片段、工具请求与结果、回合结束。 | PostgreSQL。                   |
| 取消恢复 | 停止后续派发，保留已展示片段并结算在途调用。       | 会话模块、模型和沙箱取消能力。 |

## 状态流转

`回合开始 → 模型步骤 → 最终回复或工具请求 → 工具结果 → 下一模型步骤 → 回合结束`。回合结束为完成、失败或取消。工具结果未知且可能有副作用时，停止回合并保留该状态，不自动重试。每位用户的插件服务在独立沙箱中运行；同一用户可在不同会话中复用自己的沙箱。

## 数据与安全边界

模型输入从会话事件投影。每个会话的事件序号单调递增；发送给客户端的流式片段先持久化。用户插件只通过受版本约束的协议暴露工具声明和结果；不接收可信 Cordis 上下文、数据库连接或平台密钥。

## 模块验收

模拟模型与两个隔离用户沙箱可完成工具闭环；重放事件可恢复会话状态；用户 A 无法调用用户 B 的工具；取消、超时和结果未知路径均有明确、不可重复的结算事件。
