# 身份与用户模块 PRD

层级：L2 模块级。状态：设计草案。所属项目：[AI Agent 平台](../project.md)。

## 模块目标与边界

让用户建立账号、登录、获得 access token，并用 token 访问自己的资料和受保护功能。模块在 `apps/api` 内负责身份验证和授权入口；用户主记录由 `packages/db` 管理。Web 只接收公开的账号资料和登录响应，不读取密码验证材料。

## 功能与依赖

| 功能 PRD                                   | 本模块职责                           | 依赖                |
| ------------------------------------------ | ------------------------------------ | ------------------- |
| [注册](../features/register.md)            | 校验资料、处理密码、创建唯一账号。   | PostgreSQL。        |
| [登录](../features/login.md)               | 验证凭据、签发短期 access token。    | PostgreSQL、Redis。 |
| [获取个人信息](../features/get-profile.md) | 验证 token、读取并返回当前用户资料。 | Redis、PostgreSQL。 |

插件和对话接口复用本模块的 token 验证结果。客户端提交的 `userId` 不能覆盖后端从 token 得到的身份。涉及工作空间时，API 在身份验证后另行检查成员资格与资源权限。

## 状态流转

`未注册 → 已注册 → 已登录 → token 过期或撤销 → 需要重新登录`。注册成功不自动创建登录会话。登录失败不改变用户账号状态；无效 token 不能访问受保护接口。

## 数据与接口边界

PostgreSQL 保存用户 ID、唯一账号标识、公开资料及密码验证材料。Redis 保存短期 token 会话。登录响应返回 token；受保护请求使用 `Authorization: Bearer <token>`。个人信息响应只包含可公开字段，不包含密码验证材料、插件凭据或平台密钥。

## 模块验收

注册账号唯一；有效凭据可登录并使用 token 访问自身资料；错误或过期 token 被拒绝；跨用户资料无法通过更换请求参数读取。具体字段和错误响应见各功能 PRD。
