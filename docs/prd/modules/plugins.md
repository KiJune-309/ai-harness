# 个人插件模块 PRD

层级：L2 模块级。状态：设计草案。所属项目：[AI Agent 平台](../project.md)。

## 模块目标与边界

让用户保存和查看自己的插件代码修订版，并在后续启用时让工具进入自己的独立沙箱。`apps/api` 负责身份验证、上传、修订版元数据和授权；`packages/ai-runtime` 通过受控桥接调用沙箱中的工具。插件代码不进入可信 API 或 Agent 进程执行。

## 功能与依赖

| 功能 PRD                                        | 本模块职责                       | 依赖                             |
| ----------------------------------------------- | -------------------------------- | -------------------------------- |
| [获取个人插件列表](../features/list-plugins.md) | 按当前用户查询修订版和启用状态。 | 身份模块、PostgreSQL。           |
| [上传个人插件](../features/upload-plugin.md)    | 校验插件包、保存不可变修订版。   | 身份模块、对象存储、PostgreSQL。 |

启用、停用和沙箱装载已在[Agent 技术设计](../../superpowers/specs/2026-10-01-agent-harness-design.md)中定义边界，作为后续独立功能 PRD 再细化。上传接口不负责装载或执行。

## 状态流转

`校验中 → 已保存且未启用 → 已启用 → 已停用`。校验失败或存储失败不产生可启用的修订版。每次上传生成不可变修订版；启用状态属于用户的安装关系，不修改已保存代码包。

## 数据与隔离

PostgreSQL 保存所属用户、修订版、摘要、对象引用和安装状态。原始插件包保存在对象存储。列表由已认证 `userId` 过滤；沙箱按用户隔离。上传包、插件服务和工具定义不会跨用户共享。工具调用不授予插件数据库连接、平台密钥或容器控制权限。

## 模块验收

用户能查看自己的插件及状态；上传合法插件后可看到未启用修订版；无效包被拒绝；用户 A 看不到或无法运行用户 B 的插件。启用与执行验收在其独立功能 PRD 中继续细化。
