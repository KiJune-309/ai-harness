# 对话模块 PRD

层级：L2 模块级。状态：设计草案。所属项目：[AI Agent 平台](../project.md)。

## 模块目标与边界

管理用户在工作空间中的会话及列表，并向 Agent 提供可持久化的回合容器。`apps/api` 负责会话归属和工作空间权限；`packages/ai-runtime` 负责 Agent 回合和事件记录。列表读取会话摘要，详情从事件记录构建。

## 功能与依赖

| 功能 PRD                                                                                            | 本模块职责                           | 依赖                     |
| --------------------------------------------------------------------------------------------------- | ------------------------------------ | ------------------------ |
| [获取对话列表](../features/list-conversations.md)                                                   | 按用户和工作空间分页返回会话摘要。   | 身份模块、PostgreSQL。   |
| [Agent 执行回合技术设计](../../superpowers/specs/2026-10-01-agent-harness-design.md#运行流程时序图) | 创建或恢复会话、追加消息和状态事件。 | Agent 模块、PostgreSQL。 |

## 状态流转

会话创建后可以包含多个回合。单个回合从 `started` 进入 `finished`、`failed` 或 `cancelled` 三种互斥结束状态；工具请求有成功、明确失败或结果未知的结算状态。同一会话同一时刻只运行一个回合。

## 数据与授权

PostgreSQL 保存会话 ID、所属用户、工作空间 ID、标题、最近活动时间以及追加式事件。列表查询同时限定已认证用户和已授权工作空间，按最近活动时间分页。用户传入的会话或工作空间标识必须经过后端授权检查。

## 模块验收

用户能看到当前工作空间内自己的会话摘要；分页不重复或漏项；未授权用户无法读取其他用户或其他工作空间的会话。Agent 事件与列表摘要保持一致。
